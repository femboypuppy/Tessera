# Keyboard shortcuts

`Mod` is ⌘ on macOS and Ctrl on Windows and Linux. Press `?` anywhere (outside a text field) for
the complete, always-current list, including shortcuts that plugins add.

## Everywhere

| Action                        | Shortcut                        |
| ----------------------------- | ------------------------------- |
| Command palette and search    | `Mod+K`                         |
| New page                      | `Mod+Alt+N` (desktop: `Mod+N`)  |
| Show or hide the sidebar      | `Mod+\`                         |
| Light or dark theme           | `Mod+Shift+L`                   |
| Settings                      | `Mod+,`                         |
| All shortcuts                 | `?` or `Mod+/`                  |

## Writing

| Action                        | Shortcut                        |
| ----------------------------- | ------------------------------- |
| Slash menu                    | `/`                             |
| Link a page                   | `[[` or `@`                     |
| Tag                           | `#` and a name                  |
| Bold, italic, underline       | `Mod+B`, `Mod+I`, `Mod+U`       |
| Undo, redo                    | `Mod+Z`, `Mod+Shift+Z`          |
| Select the current block      | `Esc`                           |
| Move blocks up or down        | `Mod+Shift+↑` / `Mod+Shift+↓`   |
| Duplicate blocks              | `Mod+D`                         |

## Markdown as you type

| Type            | You get           |
| --------------- | ----------------- |
| `# `, `## `, `### ` | Headings      |
| `- ` or `* `    | Bulleted list     |
| `1. `           | Numbered list     |
| `[] `           | To-do             |
| `> `            | Quote             |
| ```` ``` ````   | Code block        |
| `---`           | Divider           |
| `**bold**`      | **bold**          |
| `*italic*`      | *italic*          |
| `~~strike~~`    | ~~strike~~        |
| `==highlight==` | ==highlight==     |

## Page tree

| Action                            | Shortcut              |
| --------------------------------- | --------------------- |
| Move up or down                   | `Alt+Shift+↑` / `↓`   |
| Nest under the page above         | `Alt+Shift+→`         |
| Move out one level                | `Alt+Shift+←`         |

## Databases

| Action              | Shortcut                     |
| ------------------- | ---------------------------- |
| Move between cells  | Arrow keys, `Tab`            |
| Edit a cell         | `Enter`                      |
| Stop editing        | `Esc`                        |
| Add a row           | `Mod+Enter`                  |
