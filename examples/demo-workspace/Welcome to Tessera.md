This is a demo workspace. It belongs to **Orbit Lab**, a small team building a traveling museum exhibit called *Leaving Earth*, about the history of space exploration. Poke around, change anything, delete anything: it's yours to play with.

> [!tip] Learn by doing
> Work through the checklist below. Check each box as you go; it takes about ten minutes. `Mod` means ⌘ on a Mac and Ctrl everywhere else.

## Your first ten minutes

### Get around

- [ ] Press `Mod+K` to open the command palette, type `apollo`, and open [[Apollo 11]].
- [ ] In the palette, search `tag:space/people` to find every person in the knowledge garden.
- [ ] Press `?` to see every keyboard shortcut. The same list is on [[Keyboard shortcuts]].
- [ ] Press `Mod+Shift+L` to switch between light and dark themes.

### Write

- [ ] Press `Mod+Alt+N` to create a page. Give it a title and press `Enter`.
- [ ] Type `/` and pick a block from the slash menu. Try `/callout` and `/table`.
- [ ] Type `# ` at the start of a line to make a heading, `- ` for a list, `[] ` for a to-do.
- [ ] Drag a block by the handle on its left to move it.
- [ ] See every kind of block in one place: [[Every block type]].

### Link

- [ ] Type `[[` and link your new page to [[Space exploration]].
- [ ] Open [[Space exploration]] and click **Backlinks** in the top bar. Your page is there.
- [ ] Open the **graph** from the palette (`Mod+K`, then "graph") and find [[Neil Armstrong]].
- [ ] Rename a page and watch every link to it update.

### Organize

- [ ] Open [[Projects]]. Switch to the **Board** view and drag a card to another column.
- [ ] Open [[Reading list]]. Filter by **Status** is *Reading*, then sort by **Rating**.
- [ ] Add a row to a database with `Mod+Enter`.

### Keep it yours

- [ ] Open **Settings** (`Mod+,`) and set your name and cursor color.
- [ ] Export this workspace as markdown from the palette ("Export"). Your notes are never locked in.
