# First steps

Ten minutes from an empty screen to a small, linked workspace. Shortcuts use <kbd>Mod</kbd> for
<kbd>⌘</kbd> on macOS and <kbd>Ctrl</kbd> elsewhere.

## 1. Create a workspace

The first time you open Tessera, you choose how to start:

- **Create an empty workspace**, to start fresh.
- **Open demo workspace**, a guided tour with about 40 pages, two databases and a small
  knowledge garden about space exploration. It's the quickest way to see everything.
- **Import from Notion**, **Import from Obsidian** or **Import markdown**, to bring your notes
  along. See [Import and export](./import-export).

## 2. Create a page

Press <kbd>Mod</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd> or click **New page** in the sidebar. Type a
title, then press <kbd>Enter</kbd> to start writing.

::: tip Mod+N in the browser
Browsers keep <kbd>Mod</kbd>+<kbd>N</kbd> for a new window, so the web app uses
<kbd>Mod</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd>. The desktop app accepts both.
:::

Give the page an icon and a cover: hover over the title and click **Add icon** or **Add cover**.

## 3. Write with blocks

Type <kbd>/</kbd> on an empty line to open the slash menu, then type to filter: `/todo`,
`/callout`, `/table`, `/code`. Or use markdown as you type:

| Type             | You get          |
| ---------------- | ---------------- |
| `# ` `## ` `### ` | Headings         |
| `- ` or `* `     | A bulleted list  |
| `1. `            | A numbered list  |
| `[] `            | A to-do          |
| `> `             | A quote          |
| ```` ``` ````    | A code block     |
| `---`            | A divider        |

Hover over a block and drag the handle on its left to move it. [The editor](./editor) covers every
block.

## 4. Link two pages

Type `[[` and start typing a page title. Pick a page with the arrow keys and <kbd>Enter</kbd>, or
choose **Create page** to make a new one and link to it in one go. Links follow renames, so they
never break.

Open the linked page and click the **Backlinks** button in the top bar: your first page is listed
there, with the sentence that links to it.

## 5. Tag it

Type `#` and a name, like `#idea`. Clicking a tag searches for every page that has it.

## 6. Make a database

Type `/database` to add an inline database, or create a full-page one from the sidebar. Add a
**Status** property of type _select_, then switch to the **Board** view and drag cards between
columns. See [Databases](./databases).

## 7. Find anything

Press <kbd>Mod</kbd>+<kbd>K</kbd> to open the command palette. Search page titles and text, jump to
a page, or run a command. Try `tag:idea`.

## 8. Make it yours

- <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd> switches between light and dark themes.
- <kbd>Mod</kbd>+<kbd>\\</kbd> hides the sidebar.
- <kbd>?</kbd> lists every keyboard shortcut. The full list is in
  [Keyboard shortcuts](./keyboard-shortcuts).
- <kbd>Mod</kbd>+<kbd>,</kbd> opens Settings: your name, cursor color, theme and workspace.
