Welcome to **Tessera**, a calm place for notes, docs and small databases. This demo workspace is a real one: change anything, it is yours.

> [!tip] Keyboard first
> Press ==Mod+K== to search and run commands, and type `/` in a page to add blocks.

## Take a tour

- [ ] Open [[Website relaunch]] to see a project page with tasks and properties
- [ ] Skim the [[2026-09-14 Kickoff|kickoff notes]] and follow a link or two
- [ ] Browse the [[Reading list]] database and sort it by rating
- [ ] Read the [[Writing guide]] before you start your own pages

## How this workspace is organized

| Area | What lives there |
| --- | --- |
| [[Projects]] | One page per project, with status, owner and due date |
| [[Meetings]] | Dated notes that link to the projects they discuss |
| [[Reading list]] | Books and essays, with ratings and tags |
