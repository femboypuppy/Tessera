Short pages that link to each other beat long pages nobody finishes.

## Principles

- **One idea per page.** Link related pages with `[[double brackets]]`.
- **Lead with the answer.** Put the decision or the summary first.
- **Use callouts sparingly.** One per page keeps them meaningful.

> Writing is thinking. To write well is to think clearly. That's why it's so hard.
> — David McCullough

## Formatting cheat sheet

| You type | You get |
| --- | --- |
| `**bold**` | **bold** |
| `==highlight==` | ==highlight== |
| `[[Page]]` | a link to a page |
| `- [ ]` | a to-do |
